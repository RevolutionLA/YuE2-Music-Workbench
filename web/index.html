乐谱加工

把一份乐谱移调、换大调小调、调速度——全部是符号运算，不跑模型，改完即时出结果。

谱面 · 原谱与加工结果改右边任一参数即实时重算
加工结果
先在上面放一份谱，再到右边选加工项。
加工结果只在这里和乐谱库里，原谱不会被覆盖。「用于⑤生成」只有点击后才写入⑤，已有不同谱会先询问；也可以存进乐谱库后再去⑤选择。
加工项可叠加，顺序由服务端固定：移调 → 调式 → 速度 → 去和弦
① 移调
正数升高、负数降低。常见用法：女声谱给男声唱降 5~7 半音，男声谱给女声唱升 5~7；差一个八度用 ±12。
② 大小调
同名（平行）大小调：主音不动，靠动 3/6/7 音级改色彩 —— 大调变忧郁，旋律会改音。
关系大小调：共用同一组音，只把调性中心挪小三度 —— 旋律一个音都不动，只改调号。
诚实边界：和弦记号只在「移调」时跟着走。调式转换不会替你重新配和声（那是作曲决策）， 想要和弦跟着变，先勾下面「去掉和弦记号」，让 ⑤ 在 full 路线下按新调重新规划。
③ 速度
两个都填时以 目标 BPM 为准（倍速忽略）。速度只改 Q: 这一行，不改变音符时值。
④ 其他
去掉后这份谱就是纯旋律谱，⑤ 会自动按 melody 路线生成（伴奏由模型配）。

RVC 音色模型
暂无音色模型。可在「⑦ 音色制作」页训练，或点下面的「导入音色文件」装入外部 .pth。
重命名后索引文件保留；删除会同时清理对应的音色索引（只删精确属于自己的那几枚，不抢邻居同名前缀）。正在被换声任务使用的音色不能删除或重命名。
为什么外部音色要另传一段音频建档？训练时那份素材不能用吗？
本机训练出来的音色不用建档：训练过程已经把素材的基频（f0）实测写进了 logs/<名字>/2b-f0nsf，卡片直接显示「音域 …Hz（来源：训练素材实测）」， 「建档音域」按钮根本不会出现——训练素材的量已经在里面了，只是没有另外存一份音频文件。
外部下载的 .pth 必须建档：它只是一个权重文件，训练它用的素材在别人机器上， 本机没有，也就没有实测音域。量不出来就只能标「无音域」，⑨ 换声页给不出变调建议。
为什么不能拿换声产物反推：换声输出唱的是源歌的音高，不含目标音色的音域信息 （实测两个不同音色的产物，中位只差 0.09 半音），反推出来的是源歌的音域，是假的。 所以只能要一段这个音色本人的干净人声，10~30 秒足够。
想要"那个人的嗓子"该走哪条路（三条路线的区别）
① 换声（RVC）：歌已经生成好了、只想把唱腔换成某个音色 → 去「⑨ 歌曲换声」。伴奏可以原样留住，这是唯一能保留原旋律与原编曲的路线。
② 翻唱（YuE2）：在 ② 歌词+style生成歌曲 页点「从参考音频识别歌词」→ 把原唱的词识别出来 → cot 选 melody 重新生成 → 同旋律、全新编曲、不保留原歌手音色。
③ 自制音色（训练）：手上没有现成模型、要用某人/自己的嗓子反复出片 → 去「⑦ 音色制作」用干声样本训练，练完自动进⑨的音色下拉框。

上面选的是本机服务器上已有的音频（生成过的歌、⑩ 分离出的干声/伴奏），换声时由服务端直接取那份文件，不需要你下载再传。留空就用上面上传的文件。
变调快捷：
量源唱的音高中枢、对照所选音色的舒适音域，给出该变几个半音（CPU 几秒，不进换声队列）。💡 只放源歌的 10~30 秒人声片段来分析即可，不必丢整首（只读前 5 分钟，带伴奏数字会被污染）。
💡 变调怎么填：先判断「歌曲里原唱的性别」和「目标音色的性别」——不同性别必须 ±12（女转男 -12 / 男转女 +12），否则会闷哑或尖细；同性别可先用 0，听感偏高/偏低再 ±3~5 微调。判断不准就先试 0，跑完听「换声人声」再调。
🎹 伴奏自动跟调：填 ±4 这类非整八度，伴奏同等转过去（否则成品里人声伴奏两个调）；填 ±12/±24 整八度只换音区、不换调，伴奏保持原调；填 ±16 这种"八度+零头"，伴奏只转零头那 ±4。原调伴奏另存一份（任务卡里"伴奏（原调）"），想自己配原调用它。

旋钮原理与出问题时怎么调（官方口径）
💡 检索强度越高音色越像，也越容易在长音/高音上出电音——出电音就往下调（0.5→0.3）。官方 FAQ 的取舍说得更准：调到 1 理论上完全没有推理源音色泄露，但音质会倒向你的训练素材——素材比原曲差时，调高反而更糊；素材优质且量大时这个旋钮不重要。protect 的含义是"没人声/气声帧里保留多少原唱特征"：数值越小越保留原唱咬字与呼吸（电音更少），拉到 0.5 = 完全不保护。
⚠️「音量跟随原唱」的方向和直觉相反：1 = 完全用模型自己算的音量（原曲动态丢失，静音处可能被填出气声）；0 = 完全跟原唱的强弱走。官方现行默认 0.25（七成跟原唱），别填 1——整首忽大忽小、压不住伴奏、静音段有杂音时往下调（0 → 完全跟原唱动态）。「音高平滑半径」是音高轨迹的中值滤波（官方 WebUI 同名旋钮，滤波核只认奇数）：默认 3；哑音、毛刺、断续明显时调到 5~7，调大会发闷，选 0 关闭。
🎯 高音没声音 / 高音发闷：优先把「变调算法」换成 fcpe（rmvpe 在高音区判成"无声"的概率更高，一判错那段就被抹平或丢声），并把「音高平滑半径」降到 0~3（调大也会闷）；还不行就检查变调值——人声被压到音色训练音域之外时，高音会直接发虚。「输出采样率」默认跟随模型原生：40k 音色上采样到 48k 不会凭空补出高频，只多一次重采样，除非特殊需要别改。

音色制作

用一段干净的人声训练 RVC 音色。训练耗时长，可以随时暂停、之后接着跑。

音色制作（用干声样本训练新音色）
点选或拖入人声样本（可多选） wav / mp3 / flac / m4a / ogg / opus / aac / wma
这里列的是本机服务器上已有的音频（⑩ 的分离产物、生成过的歌），按住 Ctrl 可多选；训练素材要干净人声，优先选「人声（去和声）」。上传的文件与这里选的可以并用，体检会把两者一起算。
🎤 怎么录音：手机自带的录音机即可（m4a 能直接用）——安静房间（关窗、关风扇空调）、离麦 20-30cm 正常说话或唱歌，录 4-6 段每段 1-2 分钟；不要加伴奏、混响、变声特效，不要背景音乐。唱歌音色选唱段、说话音色选说话，或两者混录。手机录的先传到电脑再选文件。
✅ 好素材的判断：回放录音能听清每个字、没有嗡嗡的房间声、音量稳定——素材质量决定音色上限，比任何参数都重要。上传完整歌曲时务必勾选自动分离，否则伴奏会被当成"人声"学进去，音色会发糊。

轮数怎么定 · 要跑多久
💡 轮数不是越高越好：素材不足时加轮数只会把毛病学得更像（发虚、电音都在）。先点「先体检素材」看时长/静音/爆音，体检给的档位就是这批素材该用的轮数；1200 轮在这张 6GB 卡上要跑一整天，只在素材极干净且要出成品时用。
训练完怎么验收（听什么算合格）
🎓 训练完成后怎么验收：先看卡片上的自检数字（有没有出声 + 高频噪声化），再到换声页用新音色换一段 30 秒的清唱试听。发虚发闷→素材太少或轮数不够；有电音/发沙要先分清是谁的账：把同一段的「原唱人声」也听一遍——原唱就电音，那是源音频的问题（YuE2 生成的歌尤其如此），换声换不掉；原唱干净、换声后才脏，是这个音色练过头或素材带噪，用「↻ 重训」填 50~60 轮重来（旧检查点会归档、旧成品先备份），或在卡片上逐档试听挑一档定稿。实测：把「音色检索强度」和 protect 调低对这种高频噪声化没有效果，别在它上面耗时间。

人声伴奏分离

把一首歌拆成人声和伴奏两条轨。分离出的伴奏可以拿去提取乐谱。

① 上传歌曲官方 PyMSS BS-Roformer · N 卡约 1.5 分钟；核显机器走 CPU，会明显更慢
点选或拖入音频文件 wav / mp3 / flac / m4a / ogg / opus / aac / wma
开了多产出「人声（去和声）」一份：副歌有叠唱/和声时，这份才是干净的训练素材。产出清单：关=人声(含和声)+伴奏两份，开=三份。
填绝对路径。目录不存在会自动创建；不能是系统盘根目录或系统目录（会被服务端拒绝）。
GPU 与生成/换声/训练共用一条串行队列：前面有任务时会显示排队位次，不会并行硬抢显存。
分离失败会说清是哪一段失败（PyMSS / 降级到 GPT-SoVITS 链 / 静音守卫判定产物为数字静音），不会给你一个空文件就报成功。
② 产物每份都可单独试听 / 下载 / 送去别的页
