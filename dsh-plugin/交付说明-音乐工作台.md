# LA 声音实验室 · 一体化音乐工作台插件

## 完成的工作

把 DSH 改造为一台一体化的音乐工作台，完全用 DSH 原生侧栏 + 主面板 Slot 实现（参考 DSH-better-sidebar 的"工作台"思路），**不再是旧的"跳转按钮 + iframe 覆盖"**。

### 架构

- **Host 半**（`src/ui-panel.mjs`，经 `cordis.patch.yml` 持久挂载，无需审批）：
  - `/lab-api/*` → 反代到本机 YuE2 网关 `http://127.0.0.1:7863/api/*`（JSON API + 音频文件）
  - `/lab/*` → 反代到网关根路径（兼容旧页面）
  - `/lab-status` → 网关存活探测（前端探活用）
  - 使用 Node 原生 `http` 直连 127.0.0.1，绕过系统代理，**无 CORS/代理问题**

- **Client 半**（`lib/client.js`，手写 CJS bundle，DSH 启动时扫描 `dsh.client` 声明并注入）：
  - 注册侧栏 `sidebar.panellist` 图标 `music-studio`（音符图标）
  - 注册主面板 `main` keyed `music-studio`（全屏音乐工作台）
  - 顶部页签导航：**创作 / 批量 / 换声 / 历史 / 音色 / 模型**
  - 数据全部通过同源 `/lab-api/*` 拉取

### 功能面板

| 面板 | 功能 | 调用网关 API |
|------|------|--------------|
| 🎵 创作 | 生成新歌（风格预设+歌词+cot/步数/种子/连发）、进度轮询、结果列表、播放/删除 | generate/start, current, list, audio, delete |
| 🗂️ 批量 | 批量队列（文本区粘贴多任务）、进度条、停止/删除 | batch/start, status, stop, delete |
| 🎤 换声 | 上传音频 + 选音色 + pitch 换声、进度轮询、播放结果 | rvc/models, convert, status, audio |
| 🕘 历史 | 全部创作+换声记录、播放/删除/清空 | history, history/{rid}/audio, delete, clear |
| 🎙️ 音色 | RVC 音色模型库、重命名/删除 | rvc/models, rename, delete |
| 🧠 模型 | YuE2 主模型切换、引擎后端 GPU/CPU 切换 | models/list, current, switch, backend/mode |

## 生效步骤（关键）

DSH 在**启动时**扫描插件包的 `dsh.client` 声明并注入浏览器 bundle。新声明需要重启 DSH web 进程：

1. 关闭 DSH web：结束运行 `bin.js web --port 3081` 的 node 进程（PID 25508），或运行 `停止声音实验室.bat`
2. 重新运行 `dsh-plugin\启动AI工作台.bat` 启动 DSH web
3. **硬刷新浏览器**（Ctrl+Shift+R）
4. 左侧栏底部出现音符图标 → 点击进入音乐工作台

> 注：若 DSH 的 client bundle 注入失败（启动日志报 "missing bundle"），需在 `dsh-plugin` 目录先执行 `pnpm install` 让 `file:../../..` 链接重新解析，再重启。
