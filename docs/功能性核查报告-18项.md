## 三、核查中发现并已处理的问题（重要）

### 7863 曾跑在"中间版本"上
- 现象：④ 乐谱加工在界面上报"网关内部出错（501）"。
- 排查：直连 7863 却是 **404**（不是 501）→ 说明常驻进程里根本没有 `/abc/edit` 路由。
- 根因：`app.py` 最后修改 = **10-08 21:44**，而 7863 进程 CreationDate = **10-08 17:32**，
  **早了 4 小时**，是整个乐谱加工特性加入之前的构建。
- 处理：`taskkill //PID <pid> //F` → 看门狗自动用新源码拉起 → 接口立即 **200**。
- 教训：**改完 `app.py` 一定要确认 7863 是新进程**（比对进程 CreationDate 与文件 mtime），
  不能只看端口有人。此坑与既有笔记"判活别只看端口号"同源。

### 501 一度是测试脚手架的假故障
- 8791 是裸 `python -m http.server`，**无法代理 POST `/lab/api/*`**，一律返 501。
- 用它测接口会得到假的"网关故障"。**接口验证一律直连 7863（免 token）或走带 token 的 3081**；
  前端真实链路是 3081（`LAB_BASE="/lab"` → `/lab/api/*`）。
